## Постановка задачи

Разработать программу, состоящую из потока `main` и нескольких экземпляров потока `marker`, с синхронизацией через критические секции и события.

### Поток `main`:
1. Захватить память под массив целых чисел (размер вводится с консоли)
2. Инициализировать элементы массива нулями
3. Запросить количество потоков `marker`
4. Запустить заданное количество потоков `marker`, передав каждому порядковый номер
5. Дать сигнал на начало работы всех потоков
6. В цикле:
   - Ждать, пока все `marker` не подадут сигнал о невозможности продолжения
   - Вывести массив на консоль
   - Запросить номер потока для завершения
   - Подать сигнал на завершение выбранному потоку
   - Дождаться его завершения
   - Вывести массив на консоль
   - Подать сигнал остальным потокам продолжить работу
7. Завершиться после завершения всех потоков

### Поток `marker`:
1. Ждать сигнал от `main` на начало работы
2. Инициализировать ГСЧ своим порядковым номером (`srand`)
3. В цикле:
   - Генерировать случайное число (`rand`)
   - Индекс = число % размер_массива
   - Если элемент == 0:
     - `Sleep(5)`
     - Записать свой номер в элемент
     - `Sleep(5)`
   - Иначе:
     - Вывести: свой номер, количество помеченных, недоступный индекс
     - Сигнал `main` о невозможности продолжения
     - Ждать сигнал от `main` (продолжить или завершить)
4. При завершении: заменить все свои элементы на 0

## Архитектура

### `SharedArray`
Потокобезопасный массив с операциями:
- `try_mark(index, id)` — попытка пометить элемент
- `clear_by_id(id)` — очистка всех элементов с заданным id
- `count_by_id(id)` — подсчёт помеченных элементов
- `snapshot()` — копия массива для вывода

### `MarkerManager`
Управляет потоками `marker`:
- `launch(count)` — запуск потоков
- `start_all()` — сигнал на старт
- `wait_all_blocked()` — ожидание блокировки всех
- `terminate(id)` — завершение конкретного потока
- `resume_all()` — продолжение работы оставшихся

## Особенности реализации

### Синхронизация
- `std::mutex` — защита массива при модификации
- `std::condition_variable` — ожидание сигналов от `main`
- `std::atomic<bool>` — флаги состояния потоков

### Обработка последнего потока
Когда остаётся один `marker`, программа автоматически завершает его без запроса ID.

### Валидация ввода
- Проверка на положительные числа
- Проверка существования ID потока
- Защита от некорректного ввода
