## Постановка задачи

Разработать консольную программу `Main` и две утилиты `Creator` и `Reporter`, которые взаимодействуют через создание отдельных процессов.

### Утилита Creator
Создаёт бинарный файл с записями о сотрудниках:
- Имя файла и количество записей получает через командную строку
- Данные вводятся с консоли
- Структура записи:
  ```cpp
  struct employee {
      int num;        // идентификационный номер
      char name[10];  // имя сотрудника
      double hours;   // количество отработанных часов
  };
  ```

### Утилита Reporter
Формирует текстовый отчёт на основе бинарного файла:
- Получает через командную строку:
  - Имя исходного бинарного файла
  - Имя файла отчёта
  - Оплату за час работы
- Вычисляет заработную плату сотрудников
- Отчёт содержит упорядоченный список сотрудников с начисленной зарплатой

### Программа Main
1. Запрашивает с консоли имя бинарного файла и количество записей
2. Запускает утилиту `Creator`, передавая параметры через командную строку
3. Ждёт завершения `Creator` через `WaitForSingleObject`
4. Выводит содержимое созданного бинарного файла на консоль
5. Запрашивает имя файла отчёта и оплату за час работы
6. Запускает утилиту `Reporter`, передавая параметры через командную строку
7. Ждёт завершения `Reporter` через `WaitForSingleObject`
8. Выводит отчёт на консоль
9. Завершает работу

## Архитектура

### `employee.h`
Структура `Employee` с методами:
- `setName()` / `getName()` — работа с именем
- `calculateSalary()` — расчёт зарплаты

### `FileHandler.h`
RAII-обёртка для файловых операций:
- `readBinaryFile()` — чтение бинарного файла
- `writeBinaryFile()` — запись бинарного файла
- `fileExists()` — проверка существования
- `createDirectory()` — создание директории

### `InputValidator.h`
Валидация пользовательского ввода:
- `getInt()` — ввод целого числа в диапазоне
- `getDouble()` — ввод дробного числа в диапазоне
- `getName()` — ввод имени с проверкой длины

### `ReportGenerator.h`
Генерация отчётов:
- `printToConsole()` — форматированный вывод в консоль
- `writeToFile()` — запись отчёта в файл

## Особенности реализации

### Ожидание завершения процессов
```cpp
WaitForSingleObject(hCreator, INFINITE);
WaitForSingleObject(hReporter, INFINITE);
```

### Валидация данных
- ID сотрудника генерируется автоматически
- Имя: от 1 до 9 символов
- Часы работы: от 1 до 168
- Почасовая ставка: от 0 до 1000

### Обработка ошибок
- Проверка существования файлов
- Обработка некорректного ввода
- Исключения C++ для ошибок выполнения
