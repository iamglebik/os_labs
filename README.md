## Сравнительный анализ C++ vs Java (ЛР №3)

### Ключевые различия

| Аспект | C++ | Java |
|--------|-----|------|
| **Синхронизация** | `std::mutex` + `std::condition_variable` | `ReentrantLock` + `Phaser` |
| **Фазовая синхронизация** | Ручная реализация барьера | Встроенный `Phaser` |
| **Управление памятью** | Ручное (умные указатели) | Автоматическое (GC) |
| **Блокировка ресурса** | RAII (`lock_guard`) | `lock()` / `unlock()` + `finally` |
| **Объём кода** | 380 строк | 330 строк (-13%) |
| **Цикломатическая сложность** | 5.67 | 5.0 |
| **Скорость выполнения** | Выше | Ниже |
| **Переносимость** | Высокая (CMake) | Очень высокая (JVM) |

### Что оказалось проще в Java?

1. **Фазовая синхронизация** — встроенный `Phaser` вместо ручной реализации
2. **Тестирование** — `ExecutorService` упрощает многопоточные тесты
3. **Код короче** — отсутствие header-файлов
4. **Управление памятью** — GC исключает утечки

### Что осталось одинаково сложным?

1. **Конкурентный доступ** — логика защиты ресурса идентична
2. **Обработка прерываний** — аккуратное управление флагами в обоих языках
3. **Риск дедлоков** — не зависит от языка

### Итоговая оценка

Обе реализации успешно решают поставленную задачу. Выбор языка зависит от приоритетов:
- **C++** — для максимальной производительности и точного контроля ресурсов
- **Java** — для быстроты разработки и лёгкости сопровождения
