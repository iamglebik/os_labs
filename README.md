## 🔬 Лабораторная работа №1 — Создание процессов

> 💡 **Быстрый переход:** [К содержанию](#-содержание) | [К сборке проекта](#-сборка-проекта)

### 📌 Постановка задачи

Разработать консольную программу `Main` и две утилиты `Creator` и `Reporter`, которые взаимодействуют через создание отдельных процессов.

**Утилита Creator:**
- Создаёт бинарный файл с записями о сотрудниках
- Имя файла и количество записей получает через командную строку
- Данные вводятся с консоли

**Утилита Reporter:**
- Формирует текстовый отчёт на основе бинарного файла
- Получает через командную строку:
  - Имя исходного бинарного файла
  - Имя файла отчёта
  - Оплату за час работы
- Вычисляет заработную плату сотрудников

**Программа Main:**
- Запрашивает параметры для Creator, запускает его и ожидает завершения
- Выводит содержимое созданного бинарного файла
- Запрашивает параметры для Reporter, запускает его и ожидает завершения
- Выводит отчёт на консоль

### 🛠️ Технологии и особенности реализации

В ветке [`feature-lab1`](https://github.com/iamglebik/os_labs/tree/feature-lab1) реализовано современное решение на **C++17** с использованием:

| Компонент | Описание |
|-----------|----------|
| `employee.h` | Структура `Employee` с методами валидации и расчёта зарплаты |
| `FileHandler.h` | RAII-обёртка для безопасной работы с бинарными файлами |
| `InputValidator.h` | Класс для проверки и фильтрации пользовательского ввода |
| `ReportGenerator.h` | Генератор отчётов с форматированным выводом в консоль и файл |
| `Creator.cpp` | Реализация утилиты создания бинарного файла |
| `Reporter.cpp` | Реализация утилиты генерации отчёта |
| `Main.cpp` | Главная программа, управляющая запуском процессов |

### 📦 Сборка проекта

[↑ К содержанию](#-содержание)

```bash
# Клонирование репозитория
git clone https://github.com/iamglebik/os_labs.git
cd os_labs

# Переключение на ветку с первой лабораторной работой
git checkout feature-lab1

# Сборка через CMake
mkdir build && cd build
cmake ..
make -j4

# Запуск тестов
./test_runner
```

- `Reporter` / `Reporter.exe` — утилита генерации отчёта
- `Main` / `Main.exe` — главная программа
- `test_runner` / `test_runner.exe` — программа для запуска тестов
